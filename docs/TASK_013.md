# Phase 7 – Prompt Builder

## Status

Planned

---

# Objective

Implement the Prompt Builder for CyberRAG.

The Prompt Builder combines the formatted context produced by the Context Builder with the user's question to construct deterministic prompts for the language model.

This task is strictly backend-only.

---

# Background

TASK_012 introduced the Context Builder, which converts retrieved CVE documents into structured evidence.

Large Language Models require carefully structured prompts to generate grounded, accurate responses.

The Prompt Builder is responsible for creating those prompts while ensuring the model only answers using the provided context.

---

# Functional Requirements

## Input

Accept:

- User query
- Context block generated by TASK_012

Example:

```python
build_prompt(
    query,
    context
)
```

---

## Output

Produce a complete prompt consisting of:

- System Prompt
- User Prompt

---

## System Prompt

The system prompt should instruct the model to:

- Answer only using the supplied context.
- Never fabricate CVEs.
- State when information is unavailable.
- Remain concise and technical.
- Preserve cybersecurity terminology.

---

## User Prompt

The user prompt should include:

- Original user question
- Structured context block

Example:

```text
Question:

How does CVE-2024-1234 work?

Context:

...

Answer:
```

---

## Prompt Templates

Support configurable prompt templates.

Avoid hard-coded prompts inside application logic.

---

## Deterministic Output

Identical input should always produce identical prompts.
